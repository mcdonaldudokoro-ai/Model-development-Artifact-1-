## Algorithms Covered

### Supervised Learning Algorithms

Supervised learning uses labeled training data. The model learns from examples where the correct answer is already known.

| Algorithm | Main Purpose | Example Use Cases |
|---|---|---|
| Linear Regression | Predicts continuous numeric values | Home price prediction, fuel efficiency estimates, monthly sales forecasting |
| Logistic Regression | Predicts class probability | Spam detection, loan default prediction, product review classification |
| Decision Tree | Uses branching decisions to classify or predict outcomes | Medical decision support, customer churn prediction, product return eligibility |
| Random Forest | Combines many decision trees for stronger predictions | Fraud detection, patient readmission risk, credit scoring |
| Support Vector Machine | Finds the best boundary between classes | Handwritten digit recognition, text classification, gene expression analysis |
| K-Nearest Neighbors | Classifies based on nearby examples | Product recommendations, anomaly detection, small dataset image classification |
| Neural Network | Learns complex patterns through connected layers | Image recognition, real-time translation, voice assistants |

---

### Unsupervised Learning Algorithms

Unsupervised learning works with unlabeled data. The model looks for patterns, groups, or hidden structure without being given the correct answer first.

| Algorithm | Main Purpose | Example Use Cases |
|---|---|---|
| K-Means Clustering | Groups similar data points | Customer segmentation, satellite image grouping, document topic discovery |
| Principal Component Analysis | Reduces the number of features while keeping important information | Feature compression, visualization, sensor data reduction |
| Generative Adversarial Network | Generates realistic synthetic outputs | Synthetic face generation, medical training images, artistic style transfer |

---

## Supervised vs. Unsupervised Learning

| Dimension | Supervised Learning | Unsupervised Learning |
|---|---|---|
| Training Data | Requires labeled examples with known answers | Uses raw, unlabeled data |
| Goal | Predict a specific output | Discover hidden patterns or structure |
| Evaluation | Measured against known labels | Evaluated by cluster quality, compression, or generated output |
| Typical Output | Prediction or classification | Clusters, reduced features, or generated samples |
| Best Used When | The target outcome is known | The goal is exploration or pattern discovery |

## How the Algorithms Relate

### Supervised Learning

Linear Regression and Logistic Regression are strong starting points because they are simple and easy to interpret. Linear Regression predicts numeric values, while Logistic Regression predicts categories or probabilities.

Decision Trees make decisions through clear branches, which makes them easier to explain. Random Forest improves this idea by combining many decision trees, reducing overfitting and improving accuracy.

Support Vector Machine and K-Nearest Neighbors both rely on distance and separation, but they use different approaches. SVM focuses on finding the best boundary between classes. KNN compares a new data point to nearby examples.

Neural Networks are more flexible because they can learn complex patterns, especially when there is enough data.

### Unsupervised Learning

K-Means Clustering finds groups in unlabeled data. PCA reduces the number of features in a dataset while keeping the most important information. GANs generate new outputs by training two networks against each other.

These unsupervised methods can also support supervised models. For example, PCA can simplify data before classification, and GANs can create synthetic training data.
